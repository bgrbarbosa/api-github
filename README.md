# Projeto de Consulta api-github

Este projeto tem como objetivo consultar através de requisição, informações de uma determinada conta no github. O mesmo foi desenvolvido na linguagem Javascript utilizando o Framework React. 

![image](https://github.com/user-attachments/assets/5053eb2f-f295-4644-934c-0bea2dbe823d)



## 🚀 Montagem de Ambiente

Essas instruções permitirão que você obtenha uma cópia do projeto em operação na sua máquina local para fins de desenvolvimento e teste.

Consulte **[Implantação](#-implanta%C3%A7%C3%A3o)** para saber como implantar o projeto.

### 📋 Pré-requisitos

Para que a aplicação rode localmente, devemos ter instalado na máquina os itens listados abaixo: <br>

Node versão 18.18.0<br>

### 🔧 Instalação passo a passo

1) Realizar o clone do projeto - git clone https://github.com/bgrbarbosa/api-github.git<br>
![image](https://github.com/user-attachments/assets/e3d4b9b6-d898-4adb-a9d9-58b86ea15905)

2) Para rodar o projeto

   2.1) Após baixar o projeto no github, ir até a raiz do mesmo e rodar o comando: npm install<br>
   2.2) Após o npm install, rodar o comando npm run dev
 
## ⚙️ Executando os testes

1) Testando o funcionamento da api

   Abrir o navegador e digitar a url http://localhost:5173 e a tela abaixo deverá ser exibida <br>
   ![image](https://github.com/user-attachments/assets/ad29d471-f149-45ff-9a67-55ddfe82ed84)

## 📦 Implantação

1) Criando um build de deploy do projeto: npm run build
